About Metbook

Metbook is a learning project created to understand web development, databases, and how to build real applications.

What We're Learning

  • Python + Flask: Web framework for handling requests
  • HTML/CSS: Building pages that work on all devices
  • SQLite: Storing data that persists
  • File uploads: Saving pictures
  • Web design: Making it look good and work on phones

The Goal

Eventually, this will be accessible from your phone over WiFi, and might even become a real app you can install on your home screen!
